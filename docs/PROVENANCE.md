file traces to one script. This page is the map. It is generated by
`docs/_gen_provenance.py` from the actual filenames that appear inside each script,
so the map cannot silently drift from the code.

## Execution order

The chain runner enforces dependency order, so re-running an upstream step
cannot silently wipe a downstream upgrade.

```
s1_build_manifest.py        -> data/manifest.json
s1_audit_core.py            -> results/audit_A, B, C
s1_effect_vs_noise.py       -> results/audit_D
s1_anchor_b3.py             -> results/audit_E
s1_field_survey.py          -> results/audit_F      (resets R2/R3/R5 to tier C)
s1_fulltext_coding.py       -> results/audit_F      (upgrades tiers from full text)
s1_gain_vs_noise.py         -> results/audit_G      (read-only)
s1_spectralsr_std_evidence.py -> results/audit_H
s1_oa_resolution.py         -> results/audit_I
s1_make_paper_figures.py    -> figures/fig1, fig2
```

`s1_fulltext_coding.py` must run after `s1_field_survey.py`. Running them in the
other order discards the tier upgrades. `run_audit_chain.py` encodes this.

## The pairing rule

Only runs whose names carry an explicit seed suffix (`_s2026`, `_s2027`, `_s2028`)
participate in method pairing. This is enforced in `s1_effect_vs_noise.py` and is
the reason `audit_E_anchor_b3.json` exists: the anchor proves the pipeline before
any negative finding is reported.

## Survey evidence tiers

`results/audit_F_field_survey.json` codes each paper on R2 (aggregation), R3 (seed
count), and R5 (test-set composition). Each coded field carries a tier A, B, or C.
Only tiers A and B count toward any omission rate. Tier C means the field could not
be confirmed without the full text, and is never read as "not reported".

The self-calibration this produces is the survey's central methodological
constraint: the abstract-level count for seed disclosure is 0 of 35, and the
full-text count is 4 of 35. Any count of "papers that do not report X" is bounded
above by the number of full texts retrieved.

## Reference resolution

`papers/references.md` is generated by `s1_make_references.py`. Every field is
copied from a source record and the source is named inline:

| Priority | Source | File |
|---|---|---|
| 1 | Crossref or OpenAlex, keyed by resolved DOI | `results/_doi_meta.json` |
| 2 | arXiv API, keyed by arXiv id | `results/_arxiv_meta.json` |
| 3 | Venue string from the survey coding | `results/audit_F_field_survey.json` |

No field is written from memory. A field no source supplies prints as
`**VERIFY: ...**` and is collected in a table at the end of the file. Eight
entries remain incomplete and each carries the reason.

One entry needed manual recovery. The DOI recorded in the survey pool for
UDAMSR (`10.1016/j.eng.2026.02.005`) resolves at Crossref with HTTP 200, but to
*Data-Efficient and Robust Reinforcement Learning for Moving Devices*, which is
not a super-resolution paper. Querying Crossref with the publisher's article
identifier `S2095809926001682` as an `alternative-id` returned the correct
record: `10.1016/j.eng.2026.01.031`. A resolution check that inspects only the
response status accepts the wrong record. The title has to agree.

## Verifying a copy of this repository

`docs/_verify_remote.py` compares every file in the working tree against the
tree held by the remote, blob for blob, using the git object hashing rule. Run
it with a token in `GH_TOKEN`:

```bash
GH_TOKEN=... python docs/_verify_remote.py
```

It prints any file missing on either side and any file whose content differs,
then a single-line verdict. The shipped state is `IDENTICAL` for all 591 files.

## Venue checks

`s1_jstars_check.py` runs in addition to the number checks. It asserts the venue
constraints the manuscript has to satisfy at IEEE JSTARS: the abstract is one
paragraph and between 150 and 250 words, the abstract carries no citations, Index
Terms are present, the Conclusion, Data and Code Availability, and Acknowledgment
sections all exist, the reference list is contiguous, every reference is cited,
no citation is dangling, tables and figures are all defined, and no banned word
or semicolon appears in the prose. It currently passes 55 assertions with zero
mismatches.
